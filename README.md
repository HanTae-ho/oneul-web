> **V5.1 매일의 명상** — V5.0에서 추가한 홈 상단 짧은 글의 이름을 `매일의 명상`으로 다듬고, 문장을 지시형 문구보다 관찰·수용·선택을 돕는 짧은 성찰문으로 전면 보정했습니다. 회복일 카드 바로 위에서 기기 로컬 날짜를 기준으로 매일 바뀌며, AI·서버 연결 없이 오프라인에서도 동작합니다. 기존 하단 `오늘의 말`은 그대로 유지합니다.

# 오늘 한 걸음

자연어 1~30분 버티기 요청은 채팅 안 원형 타이머로 실행하고, `도움이 되는 글`은 앱의 기존 검토 글(READS)에서 채팅 안에 보여줍니다. 내정보는 상단 오른쪽에서 열며 하단 다섯 번째 자리는 향후 `소셜`에 사용합니다.


중독 회복을 돕는 웹앱. 알코올·도박·약물.

브라우저에서 열면 그냥 되고, 홈 화면에 추가하면 앱처럼 열린다.
비행기 모드에서도 충동 타이머와 기록은 그대로 돌아간다.

> **회복 기록은 이 기기 밖으로 나가지 않는다.**
> 감정·충동·재발·HALT·복약·기분 기록은 브라우저 안에만 있다.
> 마음프로에서는 앱 내부 기능으로 해결되지 않는 일반 대화를 사용자가 직접 보낼 때만 AI 서버를 사용한다.

## 1. 무엇이 어디 있나

```
oneul-web/                    ← 이 저장소. 앱 전부
  index.html                  앱 하나. 전부 이 안에 있다 (약 1,600줄)
  sw.js                       서비스 워커. 고칠 때마다 V 를 올려야 한다
  manifest.json               홈 화면에 추가될 때 쓰는 정보
  icon-*.png                  아이콘

깃허브 밖 (내 컴퓨터)
  오늘 한 걸음_자원시트.gs        공개 자원·음악·앱 설정을 내보내는 Apps Script
  오늘한걸음_AI.gs               마음프로 전용 Apps Script. API 키는 여기의 Script Properties에만 둔다
```

**앱은 파일 하나다.** CSS 도 JS 도 index.html 안에 있다.
빌드 도구도 없고 설치할 것도 없다. 고쳐서 올리면 끝이다.
우리도서관과 같은 방식이다.

---

## 2. 어떻게 돌아가나

```
   기기 (index.html)
        │
        │  ① 회복 기록을 읽고 쓴다
        ├─────────────────────▶  브라우저 저장소 (이 기기 안)
        │                        감정 · 충동 · HALT · 재발 · 자기 전 체크
        │                        ↑ 여기서 한 발짝도 나가지 않는다
        │
        │  ② 자원 목록을 받는다 (선택)   ┌──────────────────┐
        └────────────────────────────▶ │  Apps Script     │
                                        │  (읽기 전용)     │
                                        └────────┬─────────┘
                                                 ▼
                                        ┌──────────────────┐
                                        │  스프레드시트    │
                                        │  모임·센터·병원  │
                                        └──────────────────┘
```

**나가는 것과 안 나가는 것을 반드시 나눠 두었다.**

| | 무엇을 | 어디에 |
|---|---|---|
| 절대 안 나감 | 감정·충동·HALT·재발·자기 전 체크·복약 | 브라우저 저장소 |
| 받아만 옴 | 자조모임·센터·병원·상담전화·음악 목록·공개 앱 설정 | 스프레드시트 (내 계정) |
| 필요한 일반 대화만 나감 | 마음프로에서 앱 내부 기능으로 처리되지 않아 AI 답변이 필요한 직접 입력 문장 | AI 전용 Apps Script → OpenAI API |

**★ 이 선을 넘지 마라.**
회복 기록을 스프레드시트로 보내는 순간, 내 개인 구글 계정이
환자 건강 민감정보의 보관처가 된다. 개인정보보호법 문제이고
병원 내부 규정 문제이기도 하다. 편해 보여도 하지 마라.

시트에는 공개해도 되는 자료만 있으므로, 웹앱 주소가 알려져도 잃을 것이 없다.

---

## 3. 시트를 안 붙여도 된다

`오늘 한 걸음_자원시트.gs` 는 **선택**이다.
붙이지 않으면 앱 안에 넣어둔 기본 목록(상담전화 6곳, 자조모임 4곳, 센터·병원 찾기)을 쓴다.

시트를 붙이면 좋은 점은 하나다 —
**모임 시간이 바뀌거나 새 센터가 생겼을 때 코드를 안 건드려도 된다.**
시트에서 한 줄 고치면 앱이 다음 날 알아서 받아온다.
다른 상담사에게 시트 편집 권한만 주면 같이 관리할 수도 있다.
`음악` 탭도 같은 방식이다. 음원이 끊기거나 권리가 바뀌면 코드를 고치지 않고 시트에서 교체한다.

붙이는 법은 `.gs` 파일 맨 위 주석에 적어두었다.

## 4. 무엇을 할 수 있나

**매일**

- 회복일 (알코올·도박·약물 따로, 여러 개 동시에)
- HALT 체크 — 배고픔·화남·외로움·피곤함. 고르면 그 자리에서 대응을 알려준다
- **매일의 명상 (V5.1)** — 홈의 회복일 바로 위. 24×24 명상문 조합으로 매일 다른 짧은 성찰글을 보여주며 576일 동안 같은 전체 조합이 반복되지 않는다. 감정을 단정하거나 행동을 명령하기보다 알아차림·수용·안전한 선택을 부드럽게 권하는 문장으로 구성한다. 기기 로컬 날짜 기준이며 AI·서버를 쓰지 않는다.
- 오늘 기분, 기존 하단 오늘의 말
- 자기 전 하루 마무리 — 기분 / 충동 / 지켰나 / **오늘의 칭찬** / **한 줄 일기**
  - 칭찬에는 '(선택)' 을 안 붙인다. 선택이라 적으면 건너뛰고, 필수로 막으면 강요가 된다.
    비운 채 저장하면 **한 번만** 권하고([그냥 버텼다] 원터치), 두 번째는 그냥 넘어간다
- 복약 체크
- **식사·잠 체크 (v28)** — 끼니와 어젯밤 잠.
  굶으면 충동이 커지고(HALT 의 H) 못 자면 판단이 흐려진다(HALT 의 T).
  몇 g·몇 시간은 묻지 않는다 — 숫자로 재게 하면 그것이 또 하나의 강박이 된다

**가족·보호자 (v28)**

- 첫 화면에서 역할을 고른다 — 당사자 / 가족·보호자 (내 정보에서 언제든 바꾼다)
- 가족 모드에서는 **회복일 카운터를 안 보여준다.**
  그 숫자는 그 사람의 것이고, 가족이 매일 보게 되면 감시가 된다
- 홈에 안내 세 갈래 — 중독 이해하기 / 위기일 때 / 나를 돌보기
- [지금 위급해요] 는 충동이 아니라 금단·자살 신호·폭력으로 간다
- 기록은 감정·하루·몸·통계만. 충동과 재발은 가족의 기록이 아니다
- 칭찬 칩도 가족용이 따로 있다 — '오늘 안 마셨다' 는 가족의 것이 아니다
- 헬프에서 가족 모임이 맨 위로 올라온다
- ★ 문구는 임상 내용이다. **팀장님 검토를 받고 배포할 것.**
  특히 '조력(enabling)' 과 '경계 정하기' 는 잘못 읽히면 가족에게 죄책감을 더 얹는다

**충동이 올라올 때**

- **지금 위험해요** 버튼 하나 → 세 갈래로 나뉜다
  - 술·도박·약물 생각이 올라와요 → 충동 대응
    (**v30** 고른 영역만 이름을 부른다. 알코올만이면 "술 생각이", 셋 다면 "술·도박·약물 생각이")
  - 몸이 이상해요 → **119** (금단은 앱이 다룰 일이 아니다)
  - 죽고 싶어요 → **109** 즉시 연결
- 충동 강도 0–10 → 5분 → 15분 → 30분 타이머
- 호흡 가이드 (4초 들이쉬고 6초 내쉬기)
- 허용 사고 체크 — "딱 한 잔만", "이번 한 번만", "나는 조절할 수 있다"
- 끝나면 강도를 다시 물어 **시작 전/후를 나란히 보여준다**

**무너졌을 때**

- 다시 시작하기 — 자책 없이 상황과 HALT 를 남긴다
- **그때의 마음 (v28)** — 죄책감·수치심·화·두려움·슬픔·후련함·아무 느낌 없음.
  죄책감("내가 한 일이 잘못됐다")과 수치심("내가 잘못된 사람이다")은 다르다.
  죄책감은 고치게 하고 수치심은 숨게 만든다. 그래서 수치심을 고르면 한마디를 붙인다
- **연속 일수는 새로 세지만 누적 회복일은 그대로 둔다.**
  지금까지 지킨 날은 없어지지 않는다. 이 앱에서 제일 중요한 규칙이다

**돌아보기**

- 충동이 올라오는 시간대 (내 위험 시간을 스스로 발견하게 된다)
- 무엇이 나를 무너뜨리나 (HALT 빈도)
- 자주 떠오르는 허용 사고
- 버티기 전/후 평균 강도 — 버티면 정말 내려간다는 나의 증거
- 최근 2주 기분
- 다시 시작할 때의 마음 (v28) — 수치심이 잦으면 따로 짚어준다



**하단 탭 (v41)**

하단은 `홈 · 기록 · 헬프 · 마음프로` 네 개만 둔다. 내정보는 홈 상단 오른쪽 사람 아이콘으로 연다. 향후 다섯 번째 자리는 `소셜`에 사용한다. 관리자 화면은 내 정보에서만 연다.
`헬프` 안의 즉시 전화 연결 영역은 **헬프콜**로 표시한다. 하단 헬프는 전체를 빨갛게 칠하지 않고 아이콘 옆에 작은 붉은 안전 포인트만 둔다. AI 기능은 헬프에서 중복 노출하지 않고 독립 **[마음프로]** 탭에서 연다.
마음프로의 프로필과 하단 탭은 **하트 안의 새싹** 아이콘으로 통일한다.

**마음프로 (V4.6 · Local-first 안내형)**

하단 **[마음프로]** 탭에서 바로 들어간다. 홈의 [마음프로와 이야기하기]도 같은 화면을 연다.
중앙의 대화영역만 스크롤되고, 하단의 **[바로 할 수 있는 것] · 입력창 · 보내기**는 고정한다. 인라인 도움글은 새 메시지가 시작되면 자동으로 닫힌다.
[바로 할 수 있는 것]은 입력창 바로 위에 작게 접어 두고, 필요할 때 펼친다. 기능을 고르면 다시 접히지만 사라지지 않아 언제든 다시 사용할 수 있다.
모임·센터·병원 결과는 긴 카드 목록으로 대화창에 계속 남기지 않는다. 답변 뒤에 [목록 보기] 같은 작은 후속 버튼만 잠깐 보여주며, 다음 메시지를 보내면 그 버튼도 사라진다.

- 처음 한 번은 무엇이 전송되는지 안내하고 사용자가 [확인하고 시작]을 눌러야 한다.
- **Local-first:** 타이머·도움글·오늘 모임·센터/병원·헬프콜·기록/통계·충동 대응·다시 시작·듣는 글·가족 안내·앱 화면 이동처럼 웹앱이 이미 처리할 수 있는 요청은 AI 서버를 호출하지 않는다.
- 로컬로 처리한 사용자 문장과 앱의 로컬 답변에는 `local=1`을 붙여 저장하고, 이후 일반 AI 대화를 보낼 때도 AI history에서 제외한다. 즉 모임이나 센터를 물었던 문장이 나중에 자동으로 AI에 따라가지 않는다.
- 일반적인 상담·대화처럼 앱 내부 기능으로 답할 수 없는 경우에만 사용자가 직접 입력한 문장을 AI 서버로 보낸다. 회복 시작일·HALT·충동·재발·복약·기분 기록은 자동 전송하지 않는다.
- 마음프로 대화 기록은 브라우저의 기존 저장소에만 남긴다. [새 대화로 비우기]로 이 대화만 지울 수 있다.
- 자살·자해, 경련·환각·심한 금단, 즉각적 폭력 위험 표현은 AI보다 먼저 기기에서 판정해 109·119·112 연결을 우선한다.
- [오늘 모임]·[가까운 센터·병원]은 현재 자원시트에서 받아둔 검증 데이터(없으면 앱 기본값)를 기기에서 필터링한다. 이 요청 때문에 OpenAI를 호출하거나 기관 후보를 AI에 전달하지 않는다.
- **V4.6 안내형 응답:** 앱 내부 기능은 곧바로 화면을 넘기지 않는다. 마음프로가 실제 앱 데이터에서 개수·대표 일정·대표 기관 등 핵심 내용을 2~4문장으로 먼저 설명하고, 그 다음 [전체 보기]/[열기] 버튼을 제공한다. 긴 목록은 채팅에 계속 쌓지 않는다.
- **위치 비교:** 사용자가 특정 지역을 직접 말하지 않은 [오늘 모임]·[가까운 센터·병원] 요청은 위치 권한 상태를 확인한다. 이미 허용되어 있으면 현재 위치를 시·도 단위로 판단하고 내정보 지역과 비교한다. 두 지역이 다르면 [현재 위치]·[설정 지역]·[내정보 지역 변경] 중 사용자가 고른다. 권한이 없으면 [현재 위치 확인] 또는 [설정 지역으로 계속]을 제시한다.
- 위치는 `Geolocation API → 시·도 근사 판정`까지만 기기 안에서 사용한다. GPS 좌표는 저장하지 않고 마음프로 AI/OpenAI로 보내지 않는다. 출장·여행일 수 있으므로 현재 위치가 다르다는 이유만으로 내정보 지역을 자동 변경하지 않는다.
- AI API 키는 절대 index.html이나 GitHub에 넣지 않는다. `오늘한걸음_AI.gs` 프로젝트의 Script Properties에만 저장한다.
- AI 서버가 연결되지 않거나 6시간 사용 한도에 걸려도 Local-first 기능은 그대로 작동한다.
- **v45:** 브라우저 네트워크/응답 형식 오류는 앱이 1회 재시도하고, OpenAI의 429·5xx·일시 네트워크 오류는 AI 서버 내부에서 1회 재시도한다. `RATE_LIMIT`은 즉시 구분해 안내하고 앱에서 무의미한 반복 호출을 하지 않는다. 앱 콘솔에는 메시지 원문 없이 오류코드만 남긴다.
- 마음프로 사용자 한도는 기본 **6시간 50회**, 전체 한도는 기본 **6시간 600회**다. Script Properties에 예전 `AI_USER_LIMIT_6H=30`이 남아 있으면 그 값이 우선하므로 **50으로 변경하거나 `SET_AI_USER_LIMIT_50()`을 한 번 실행**한다.

AI 연결 순서:

1. `오늘한걸음_AI_v1.3.gs`를 별도 Apps Script 프로젝트에 붙인다.
2. 프로젝트 설정 → Script Properties에 `OPENAI_API_KEY`를 넣는다. 모델은 기본 `gpt-5.6-terra`이고 `OPENAI_MODEL`로 바꿀 수 있다.
3. `CHECK_AI_SETUP` → `TEST_AI` 순서로 확인한다.
4. 웹 앱으로 배포한다(실행 사용자: 나 / 액세스: 모든 사용자).
5. 자원시트 GS를 v1.7로 교체하고 `MAKE_SHEETS`를 실행하면 [설정] 탭이 생긴다.
6. [설정]의 `AI_URL` 값에 AI 웹앱의 `/exec` 주소를 넣는다. **API 키는 절대 넣지 않는다.**
7. 자원 서버도 기존 배포에서 새 버전으로 재배포하고 `SHOW_AI_CONFIG`로 확인한다.

## 5. 고칠 때 조심할 것

**★ sw.js 의 V 를 반드시 올려라.**

(v32 부터 이유가 하나 더 늘었다. 앱이 서버의 `sw.js` 를 읽어 판을 비교하고
 "새 판이 나와 있습니다" 를 띄운다. V 를 안 올리면 아무도 새 판을 못 받는다.)

```js
const APP_VERSION = 'V5.1';  // ← sw.js, 사용자에게 보이는 앱 버전
const V = 'ohg-v501';        // ← sw.js 내부 캐시 리비전
const BUILD = 'V5.1';        // ← index.html, APP_VERSION 과 동일
```

### 버전 관리 규칙 (V4.6부터)

- **현재 기준본:** `V5.1`
- **버그 수정·오류 수정·문구/레이아웃 보정:** 앞 숫자는 유지하고 소수점 숫자를 올린다. 예: `V4.6 → V4.7 → V4.8`.
- **새 기능 추가·기능 구조의 의미 있는 변경:** 앞 숫자를 올리고 소수점은 `0`으로 초기화한다. 예: `V4.8 → V5.0`.
- `V5.0`은 홈에 새 일일 성찰 기능을 추가했기 때문에 major 버전을 올린 첫 적용 사례이고, `V5.1`은 그 기능의 명칭·문장을 보정한 minor 판이다.
- `V4.10`도 허용한다. 새 판 비교는 문자열의 숫자를 붙여 비교하지 않고 **앞 숫자(major)와 소수점 숫자(minor)를 따로 비교**한다. 따라서 `V5.0 > V4.10 > V4.9` 순서가 정확히 유지된다.
- `BUILD`와 `APP_VERSION`은 항상 같은 값을 쓴다.
- `sw.js`의 `V`는 사용자 버전이 아니라 **캐시 교체용 내부 리비전**이다. 기존 `v46` 사용자가 V4.6 전환판도 새 판으로 감지할 수 있도록 숫자형 키를 유지한다.
  - `V4.6 → ohg-v406`
  - `V4.7 → ohg-v407`
  - `V4.10 → ohg-v410`
  - `V5.0 → ohg-v500`
  - `V5.1 → ohg-v501`

안 올리면 **아무리 고쳐도 옛 화면이 그대로 나온다.**
우리도서관에서 여러 번 당한 자리다.

**★ 매일의 명상은 서버 시간을 쓰지 마라.**

홈 상단 `매일의 명상`은 `dailyHomeText()`가 기기 로컬 연·월·일을 기준으로 고른다. 앱을 자정 넘겨 계속 켜둔 경우에도 1분 시계/화면 복귀 때 날짜가 바뀌었는지 확인한다. AI나 자원시트와 연결하지 않는다.

**★ 날짜는 `ymd()` 로 세라. `toISOString()` 을 쓰지 마라.**

`toISOString()` 은 UTC 라서 한국 시간 새벽 0시~9시 기록이 전날로 밀린다.
하루의 3분의 1이 엉뚱한 날에 들어간다. 파일 안에 `ymd()` 를 만들어 두었으니 그것만 써라.

**★ 이름이 겹치는지 보라.**

index.html 은 파일 하나라 위쪽 상수와 아래쪽 상수가 부딪히기 쉽다.
겹치면 화면이 안 뜨는데, 그때는 위쪽에 빨간 띠로 줄 번호가 나온다.

**★ 사람마다 다른 말은 하드코딩하지 마라 (v30).**

`술·도박` 이라고 적어두었더니 약물 회복 중인 분에게는 자기 자리가 없었고,
`예전에 마시거나 하던 시간` 은 도박·약물 쪽에 남의 말이었다.
`URGEWORD` 와 `riskVerb()` 가 고른 영역에 맞춰 말을 고른다. 새 문구를 쓸 때도 이 둘을 써라.

**★ 바깥 링크는 `window.open` 으로 열어라 (v28).**

홈 화면에 설치해서 쓰면(standalone) 브라우저가 `target="_blank"` 를 무시하고
앱 창 안에서 그냥 연다. 그러면 돌아올 길이 없다.
그래서 `document` 에 클릭을 하나 걸어 `http(s)` 링크만 새 창으로 연다.

옵션에 `noopener` 를 넣으면 `window.open` 이 **규칙상 늘 null 을 돌려준다.**
그것을 "팝업이 막혔다" 로 읽어서 결국 이 창에서 열렸다.
옵션 없이 열고 받은 창의 `opener` 만 끊는다.

**★ `beforeinstallprompt` 는 `<head>` 맨 위에서 잡아라 (v28).**

설치 신호는 딱 한 번, 그것도 아주 이르게 온다.
본문 스크립트가 다 읽힌 뒤에 받으려 했더니 이미 지나간 뒤였고,
그래서 [홈 화면에 추가] 를 눌러도 아무 일이 없었다.
지금은 `<head>` 의 작은 스크립트가 `window.__addEvt` 에 담아둔다. **그 자리를 옮기지 마라.**

**★ Apps Script 는 '새 배포' 를 누르지 마라.**

```
배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포     ○
배포 → 새 배포                                          ✗ 주소가 바뀐다
```

**★ 이모지를 쓰지 마라. 아이콘은 전부 직접 그린 SVG 다.**

처음엔 이모지를 썼는데 내 컴퓨터에서 빈 네모(□)로 깨졌다.
2014년 이후 이모지부터 폰트에 없었고, 기기마다 없는 글자가 달라
하나씩 바꿔가며 확인하는 건 끝이 없었다. 그래서 전부 SVG 로 바꿨다.

아이콘은 index.html 안 `const ICO = {...}` 에 모여 있다.
새 아이콘이 필요하면 반드시 거기에 그려 넣어라. viewBox 는 24x24 로 통일.

```js
ico('hungry')            일반 크기 (24px)
ico('hungry', 'ic-i')    글줄 안에 들어가는 작은 크기 (17px)
```

선 굵기와 색은 CSS 의 `.ic-s` 가 잡는다. 색은 `currentColor` 라
부모의 글자색을 따라간다 — 그래서 고를 때 저절로 색이 바뀐다.

**★ 상담전화 번호는 함부로 바꾸지 마라.**

이 앱에서 가장 중요한 데이터다. 바꾸기 전에 실제로 걸어서 확인하라.
자살예방 상담은 2024년 1월부터 여러 회선이 **109** 로 통합됐다.

## 6. 아직 안 되는 것

**앱이 완전히 닫힌 상태의 정시 시스템 알림은 아직 지원하지 않는다.**
앱이 열려 있거나 다시 활성화되었을 때는 등록한 복약·식사·수면·위험 시간대를 확인해 앱 안에서 챙길 수 있다.
앱이 완전히 닫혀 있어도 정해진 시각에 잠금화면 알림을 보내려면 Web Push + 별도 알림 서버/스케줄러가 필요하며, 이 기능은 아직 붙이지 않았다.
(내 정보에서 위험 시간대를 등록해두면 앱을 열었을 때 홈에서 먼저 말을 건다.)

**위치 기반 알림과 도박 앱 차단은 넣지 않았다.**
기술적으로 어렵기도 하지만, "술 파는 곳 근처입니다" 라는 알림은
그 자체가 자극이 될 수 있어서 뺐다.

**AI는 인터넷이 없을 때 동작하지 않는다.** 기존 충동 타이머·기록·내장 도움글은 오프라인에서도 계속 쓸 수 있지만,
AI 응답은 별도 서버와 외부 AI API가 필요하다. AI가 연결되지 않을 때도 위기 전화와 기존 도움 기능이 먼저 남아 있어야 한다.

## 7. 아직 하지 않은 숙제

앱을 남에게 주기 전에 반드시 끝낼 것.

- [ ] **개인정보 처리방침** — 기록이 기기 안에만 있다는 사실을 글로 명시
- [ ] **면책 고지** — "이 앱은 치료를 대신하지 않습니다" (앱 안에는 넣어두었다)

      모임 시간·장소를 올리기 전에 각 연합단체와 이야기해야 한다
- [ ] 상담전화 번호 실제 확인 (1342 는 v31 에서 확인해 고쳤다. 나머지도 한 번씩 걸어볼 것)
- [ ] 병원 내부 검토 — 환자에게 권할 것이라면 반드시

## 8. 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| 고친 게 안 보인다 | sw.js 의 V 를 올렸나 |
| 화면이 하얗게 멈춤 | 위쪽 빨간 띠에 줄 번호가 나온다. 대개 이름 겹침 |
| 기록이 다 사라졌다 | 브라우저 데이터를 지웠나. 내 정보 → 파일로 내보내기를 습관 들이자 |
| 날짜가 하루씩 밀린다 | `toISOString()` 을 쓴 곳이 생겼다 |
| 자원 목록이 안 온다 | 내 정보 → 자원 목록에 상태가 적힌다. Apps Script 액세스 권한이 '모든 사용자'인가 |
| 홈 화면 추가가 안 보인다 | https 로 열고 있나. GitHub Pages 는 https 다 |

## 9. 올리는 법

우리도서관과 똑같다.

```
1. 깃허브에 저장소를 만든다 (oneul-web)
2. index.html · sw.js · manifest.json · icon-*.png 를 올린다
3. Settings → Pages → Branch: main / (root) → Save
4. 몇 분 뒤 https://<아이디>.github.io/oneul-web/ 이 열린다
```

**저장소를 공개로 두어도 된다.** 소스에는 개인정보가 없다.
자원 시트 주소도 코드에 넣지 말고 앱의 [내 정보]에서 넣는다.

npm install playwright        (처음 한 번)

다크 모드 → 새로고침 후 데이터 유지. 마지막에 자바스크립트 오류를 모아 보여준다.
