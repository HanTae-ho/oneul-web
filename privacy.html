개인정보처리방침

시행일: 2026년 9월 8일 · 적용 대상: 오늘 한 걸음 웹/PWA/Android 앱

핵심부터 안내합니다.
오늘 한 걸음의 감정·충동·재발·복약·수면·12단계·회복 실천도구·자가점검 같은 개인 회복기록은 기본적으로 현재 기기 안에 저장되며, 자원목록 서버나 마음프로에 자동으로 전송되지 않습니다. 다만 사용자가 마음프로에 직접 보내는 대화와 ‘앱에 바라는 점’에 직접 작성해 보내는 내용은 답변 생성 또는 의견 접수를 위해 외부 서버로 전송됩니다.

1. 운영 원칙

  • 일반 사용자는 회원가입이나 로그인 없이 앱을 사용할 수 있습니다.
  • 개인 회복기록은 ohg.v1 저장영역을 사용해 현재 기기에 보관합니다.
  • 회복기록을 운영자의 Google Sheet, 자원목록 서버, 의견 서버 또는 마음프로에 자동 업로드하지 않습니다.
  • 광고 SDK와 사용자 행동 분석용 광고·추적 SDK를 사용하지 않습니다.
  • 마음프로와 의견 보내기는 선택 기능입니다. 사용하지 않아도 다른 회복 기능을 이용할 수 있습니다.

2. 기기 안에서 처리하는 정보

앱 기능을 위해 다음 정보가 사용자의 기기 안에 저장될 수 있습니다.

  • 역할(당사자/가족·보호자), 회복 영역, 회복 시작일, 목표, 사용자가 정하거나 위치 확인으로 정한 시·도 수준의 지역
  • 위험 시간대, 습관, 복약·처방·외래 일정, 식사·수면 설정과 체크 기록
  • 기분, HALT, 충동, 다시 시작 기록, 하루 마무리, 몸 상태 관련 기록
  • 12단계 점검, 회복 실천도구, 가족 도구, 미래의 나에게 작성한 내용
  • 자가점검의 검사명·검사일·총점·결과구간. 문항별 원문 응답은 저장하지 않습니다.
  • 마음프로 대화 기록과 앱 설정

이 정보는 사용자가 직접 ‘파일로 내보내기’를 하지 않는 한 앱이 별도 운영 서버로 백업하지 않습니다.

3. 위치정보

사용자가 현재 위치 확인을 선택한 경우 브라우저의 Geolocation API를 통해 현재 좌표를 일시적으로 확인합니다. 좌표는 앱 안에서 가장 가까운 시·도 수준 지역을 판단하는 데 사용하고, 원래 GPS 위도·경도는 저장하지 않으며 마음프로 또는 자원 서버로 전송하지 않습니다.

사용자가 최종적으로 선택한 시·도 수준 지역은 모임·기관 찾기 등에 사용하기 위해 기기에 저장될 수 있습니다. 위치 권한을 허용하지 않아도 지역을 직접 선택해 사용할 수 있습니다.

4. 네트워크를 통해 처리되는 정보

4-1. 자원목록

자조모임, 상담전화, 센터·병원 같은 공개 자원목록을 최신 상태로 받기 위해 Google Apps Script 서버에 GET 요청을 보냅니다. 앱은 이 요청에 개인 회복기록을 첨부하지 않습니다.

웹 통신 과정에서 IP 주소, 브라우저/기기 정보, 요청 시각과 같은 통상적인 접속 정보는 호스팅·통신 서비스 제공자가 보안 및 서비스 운영을 위해 처리할 수 있습니다.

4-2. ‘앱에 바라는 점’

사용자가 의견을 작성하고 보내기를 누르면 다음 정보가 Google Apps Script 기반 의견 서버로 전송됩니다.

  • 사용자가 직접 작성한 의견 내용
  • 앱 버전

이름, 회복 영역, 회복 시작일, 회복기록, 자가점검 결과, 위치정보는 앱이 자동으로 첨부하지 않습니다. 의견 내용은 기능 개선과 오류 확인을 위해 운영자가 확인하는 저장소에 보관될 수 있으며, 운영 목적 달성 후 삭제합니다. 장기 보관이 필요하지 않은 의견은 1년 이내 정리하는 것을 원칙으로 합니다.

의견란에는 건강정보, 실명, 연락처 등 민감하거나 식별 가능한 개인정보를 적지 않는 것을 권합니다.

4-3. 마음프로

마음프로는 Local-first 방식입니다. 타이머, 앱 화면 이동, 자원 찾기, 위기 안내처럼 앱 안에서 처리할 수 있는 요청은 가능한 한 기기 안에서 처리합니다.

일반적인 대화처럼 AI 답변이 필요한 경우에만 다음 정보가 Google Apps Script 중계 서버를 거쳐 OpenAI API로 전송됩니다.

  • 기기에서 임의 생성한 익명형 클라이언트 식별값
  • 사용자가 현재 전송한 메시지
  • 대화 주제와 앱 버전
  • 문맥 유지를 위한 최근 일반 AI 대화 최대 8개(로컬 처리 대화는 제외)

내 발자취, 회복 시작일, HALT, 충동·재발, 복약, 자가점검 점수, 12단계·회복 실천도구 기록은 마음프로 요청에 자동 첨부하지 않습니다.

마음프로에 사용자가 직접 건강상태, 중독경험, 복약내용 등을 입력하면 그 문장 자체에는 건강·민감정보가 포함될 수 있습니다. 꼭 필요한 내용만 입력해 주세요.

OpenAI의 일반 API 서비스는 서비스 제공 및 오남용 방지를 위해 API 입력·출력을 최대 30일 보관할 수 있습니다. 실제 처리 위치는 OpenAI 및 재처리자의 글로벌 인프라에 따라 달라질 수 있습니다.

OpenAI 데이터 정책: openai.com/enterprise-privacy
OpenAI 재처리자 목록: openai.com/ko-KR/policies/sub-processor-list

5. 외부 서비스

서비스목적전달되는 내용
GitHub Pages웹앱·처리방침 제공통상적인 웹 접속 정보가 호스팅 과정에서 처리될 수 있음
Google Apps Script / Google Sheets공개 자원목록 제공, 의견 접수, 마음프로 API 중계자원목록 요청에는 회복기록 없음. 의견은 작성내용+앱버전. AI 중계는 제4-3항의 요청 데이터
OpenAI API마음프로 일반 대화의 AI 답변 생성제4-3항의 AI 요청 데이터

Google 및 OpenAI는 글로벌 인프라를 사용하므로 데이터가 대한민국 밖에서 처리될 수 있습니다. 마음프로 데이터는 사용자가 메시지를 전송할 때 HTTPS로 전송되며, OpenAI의 처리 위치는 공개 재처리자 목록에 따라 변경될 수 있습니다.

6. 보유기간과 삭제

  • 기기 내부 회복기록: 사용자가 삭제할 때까지 기기에 남습니다. ‘나 → 내 정보 · 설정 → 기록 관리 → 전체 지우기’ 또는 앱/브라우저 데이터 삭제로 지울 수 있습니다.
  • 마음프로 기기 내 대화: ‘새 대화로 비우기’로 마음프로 대화만 삭제할 수 있습니다.
  • 백업 파일: 사용자가 직접 만든 JSON 파일은 사용자가 보관·삭제합니다.
  • 의견: 운영 목적 달성 후 삭제하며, 장기 보관이 필요하지 않은 의견은 1년 이내 정리하는 것을 원칙으로 합니다.
  • OpenAI API 처리 데이터: OpenAI의 일반 API 정책에 따라 입력·출력이 최대 30일 보관될 수 있습니다.

앱에는 일반 사용자 계정이 없으므로 별도의 회원탈퇴 절차는 없습니다.

7. Android 앱 권한과 기기 기능

Android 설치 앱은 예약 알림과 음성 안내를 위해 알림, 정확 알림, 부팅 후 재예약, 화면이 꺼진 상태의 예약 작업에 필요한 Android 기능을 사용합니다. 마음프로 답변 읽기와 이완 안내는 기기의 Text-to-Speech(TTS)를 사용합니다.

현재 앱은 음성 녹음을 위한 마이크, 카메라, 연락처를 회복 기능을 위해 사용하지 않습니다. 위치 확인은 제3항과 같이 사용자가 선택할 때 웹 위치 권한을 통해 수행합니다.

8. 외부 링크

앱에서 자조모임·기관 홈페이지, 음악 서비스 등 외부 사이트를 사용자가 직접 열 수 있습니다. 외부 사이트를 연 이후의 개인정보 처리는 해당 서비스의 개인정보처리방침이 적용됩니다.

9. 이용자의 선택과 권리

  • 위치 권한은 거부할 수 있으며 지역을 직접 선택할 수 있습니다.
  • 마음프로와 의견 보내기는 사용하지 않아도 됩니다.
  • 기기 내부 기록은 언제든 내보내기, 불러오기 또는 전체 삭제할 수 있습니다.
  • 마음프로 기기 내 대화는 별도로 비울 수 있습니다.

서버에 제출한 의견의 확인·삭제 등 개인정보 관련 문의는 아래 문의 방법을 이용해 주세요.

11. 처리방침 변경

앱 기능, 외부 서비스, 개인정보 처리 방식이 바뀌면 이 처리방침도 함께 갱신합니다. 중요한 변경은 앱의 버전 기록 또는 안내 화면을 통해 알립니다.
