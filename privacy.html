개인정보처리방침

시행일: 2026년 9월 9일 · 오늘 한 걸음 웹/PWA/Android 앱

핵심 안내
오늘 한 걸음은 회원가입 없이 사용할 수 있는 Local-first 회복지원 앱입니다. 회복기록은 기본적으로 사용자의 기기에 저장되며 별도 운영 서버로 자동 백업하지 않습니다. 마음프로 AI를 사용하는 경우에도 저장된 회복기록을 자동 첨부하지 않고, AI 답변에 필요한 입력 내용과 제한된 최근 대화만 외부 서비스에서 처리합니다.

1. 무엇을 왜 처리하나요?

오늘 한 걸음은 회복일 확인, 기록·통계, 일정·알림, 12단계·회복 실천도구, 자가점검, 지역 자원 안내, 마음프로 AI 답변, 이용자 의견 접수 등 앱 기능을 제공하기 위해 필요한 정보를 처리합니다.

  • 기기 안에 저장될 수 있는 정보: 회복 시작일, 회복 영역, 기분·HALT, 충동·재발, 복약·외래·수면·습관, 일정·알림, 12단계·회복 실천도구, 자가점검 결과, 마음프로 대화와 앱 설정 등
  • 건강·중독·복약과 관련된 내용은 이용자가 입력하는 내용에 따라 민감한 건강정보를 포함할 수 있습니다.
  • 회원가입·로그인을 요구하지 않으며 이름·이메일·전화번호를 계정 정보로 수집하지 않습니다.
  • 광고 또는 사용자 행동 추적을 위한 분석 SDK를 사용하지 않습니다.
  • 기기 기록은 사용자가 직접 내보내지 않는 한 별도 운영 서버로 자동 백업하지 않습니다.
2. 마음프로 AI는 어떤 정보를 보내나요?

마음프로는 앱 기능으로 처리할 수 있는 요청을 먼저 기기에서 처리하고, AI 답변이 필요한 경우에만 외부 AI 서비스에 요청합니다. 마음프로 AI 사용은 최초 설정에서 기본적으로 켜져 있지만 사용자가 해제할 수 있으며, 이후에도 ‘내 정보 · 설정 → 앱’에서 언제든 켜거나 끌 수 있습니다.

AI 요청 시 전송되는 정보

  • 계정·실명과 직접 연결하지 않는 무작위 식별값(clientId)
  • 사용자가 마음프로에 입력한 현재 메시지
  • 대화 주제와 앱 버전
  • 최근 AI 대화 최대 8개

자동으로 전송하지 않는 정보
내 발자취, 회복 시작일, HALT, 충동·재발, 복약, 자가점검 점수, 12단계·회복 실천도구 등 기기에 저장된 회복기록은 AI 요청에 자동 첨부하지 않습니다.

사용자가 마음프로에 건강·중독·복약·실명·전화번호·주소·병원명 등을 직접 입력하면 그 내용 자체는 AI 답변을 위해 함께 전송될 수 있습니다. 필요한 내용만 입력해 주세요.

마음프로 AI를 끄면 외부 AI 요청은 하지 않으며, 타이머·도움글·모임·기관 안내 등 기기에서 처리하는 기능은 계속 사용할 수 있습니다.

3. 외부 서비스와 국외 처리는 어떻게 이루어지나요?

오늘 한 걸음은 개인정보를 광고·판매 목적으로 제공하지 않습니다. 다만 앱 기능 제공에 필요한 범위에서 다음 외부 서비스를 이용하며, 서비스 제공 과정에서 정보가 처리될 수 있습니다.

국외 처리
Google은 전 세계의 서버를 운영하고 있으며, OpenAI도 API 제공을 위해 여러 국가의 인프라와 하위처리자를 이용할 수 있습니다. Wikimedia Foundation도 Wikimedia Commons 등 Wikimedia 서비스를 국제적으로 운영합니다. 관련 데이터는 해당 기능을 사용하는 시점에 인터넷을 통해 대한민국 밖에서 처리될 수 있습니다.

OpenAI API에 전송된 데이터는 기본적으로 모델 학습에 사용되지 않습니다. 일반적인 API 악용방지 로그에는 고객 콘텐츠가 포함될 수 있으며 기본적으로 최대 30일 보관될 수 있습니다. 실제 처리 위치와 보관 방식은 각 서비스의 운영정책·계정 설정에 따라 달라질 수 있습니다.

4. 위치·Android 권한·자동수집은 어떻게 사용하나요?

위치
사용자가 ‘현재 위치 확인’을 선택한 경우 위치 좌표를 일시적으로 사용해 시·도 수준 지역을 정합니다. 원래 GPS 좌표는 저장하지 않고 마음프로에 전송하지 않으며, 위치 확인 대신 지역을 직접 선택할 수 있습니다.

Android 기능
Android 앱은 예약 알림, 화면이 꺼진 상태의 예약 작업, 부팅 후 알림 재예약, 마음프로·이완 음성 안내(TTS)에 필요한 기능을 사용합니다. 현재 Android 패키지는 마이크·카메라·연락처·정밀/근사 위치 권한을 요구하지 않습니다.

자동수집
앱 자체에는 광고·행동분석용 추적 SDK가 없습니다. 다만 웹 호스팅·네트워크·외부 API 사업자는 보안과 서비스 운영을 위해 IP 주소, 브라우저·기기 정보, 접속 시각 등 일반적인 서비스 로그를 자체 정책에 따라 처리할 수 있습니다.

5. 얼마나 보관하고 어떻게 삭제·보호하나요?
  • 기기 내부 회복기록: 사용자가 삭제할 때까지 기기에 보관되며 ‘나 → 내 정보 · 설정 → 기록 관리 → 전체 지우기’에서 삭제할 수 있습니다.
  • 마음프로 기기 내 대화: ‘새 대화로 비우기’로 삭제할 수 있습니다.
  • 백업 파일: 사용자가 직접 생성·보관·삭제합니다.
  • 앱에 바라는 점: 운영 목적 달성 후 삭제하며 장기 보관이 필요하지 않은 경우 1년 이내 정리합니다.
  • 마음프로 중계: 현재 운영 구조는 대화 원문을 Google Sheet·Drive·Script Properties에 대화기록 형태로 별도 저장하지 않도록 구성합니다.
  • OpenAI API: 기본 악용방지 로그는 최대 30일 보관될 수 있으며 법적 의무 등 예외가 적용될 수 있습니다.

보호 원칙
AI API 키는 앱 화면이나 공개 자원 시트에 넣지 않고 서버 측에서 관리합니다. 외부 전송은 필요한 항목으로 제한하고, 저장된 회복기록을 AI 요청에 자동 첨부하지 않으며, 외부 통신은 HTTPS 기반 서비스 경로를 사용합니다.

일반 사용자 계정이 없으므로 별도의 회원탈퇴 절차는 없습니다.

6. 이용자는 무엇을 선택·변경할 수 있나요?
  • 최초 설정에서 개인정보처리방침을 확인한 뒤 앱을 시작합니다.
  • 마음프로 AI는 최초 설정에서 기본 ON이지만 시작 전에 해제할 수 있고, 이후에도 ‘내 정보 · 설정 → 앱’에서 언제든 사용/사용 안 함을 변경할 수 있습니다.
  • 위치 확인은 선택 사항이며 지역을 직접 입력할 수 있습니다.
  • ‘앱에 바라는 점’은 이용자가 직접 작성·전송하는 선택 기능입니다.
  • 기기 기록은 언제든 내보내기·불러오기·삭제할 수 있습니다.
  • 앱에서 외부 사이트를 직접 연 이후에는 해당 서비스의 개인정보처리방침이 적용됩니다.
