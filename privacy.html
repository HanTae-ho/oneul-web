개인정보처리방침

시행일: 2026년 9월 8일 · 오늘 한 걸음 웹/PWA/Android 앱

핵심 안내
오늘 한 걸음은 회원가입 없이 사용할 수 있으며, 회복기록은 기본적으로 현재 기기에 저장됩니다. 저장된 회복기록을 마음프로에 자동으로 보내지 않습니다. 다만 사용자가 마음프로에 직접 보낸 대화와 ‘앱에 바라는 점’은 해당 기능 제공을 위해 외부 서버로 전송됩니다.
1. 어떤 정보를 처리하나요?

기분·충동·재발·복약·외래·수면·12단계·회복 실천도구·자가점검 결과·설정 등 사용자가 앱에 기록한 내용은 기기에 저장될 수 있습니다.

  • 회원가입·로그인을 요구하지 않습니다.
  • 광고 또는 사용자 행동 추적용 SDK를 사용하지 않습니다.
  • 기기 기록은 사용자가 직접 내보내지 않는 한 별도 운영 서버로 자동 백업하지 않습니다.
2. 언제 외부로 전송되나요?

마음프로
AI 답변이 필요한 경우에만 익명형 기기 식별값, 현재 메시지, 대화 주제, 앱 버전, 최근 일반 AI 대화 최대 8개가 Google Apps Script를 거쳐 OpenAI API로 전송됩니다.

자동으로 보내지 않는 정보
내 발자취, 회복 시작일, HALT, 충동·재발, 복약, 자가점검 점수, 12단계·회복 실천도구 기록은 마음프로 요청에 자동 첨부하지 않습니다.

앱에 바라는 점
사용자가 직접 작성한 의견과 앱 버전만 Google Apps Script 기반 의견 서버로 전송됩니다.

자원목록
자조모임·기관 등 공개 자원목록을 받기 위해 서버에 요청하지만 개인 회복기록은 첨부하지 않습니다.

마음프로 또는 의견란에 사용자가 직접 건강·중독·복약·실명·연락처 등을 적으면 그 내용 자체가 전송될 수 있습니다. 필요한 내용만 입력해 주세요.
3. 위치와 Android 권한은 어떻게 사용하나요?

‘현재 위치 확인’을 선택한 경우 위치 좌표를 일시적으로 사용해 시·도 수준 지역을 정합니다. 원래 GPS 좌표는 저장하지 않으며 마음프로에 전송하지 않습니다. 위치 권한을 거부하고 지역을 직접 선택할 수도 있습니다.

Android 앱은 예약 알림, 부팅 후 알림 재예약, 화면이 꺼진 상태의 예약 작업, 마음프로·이완 음성 안내(TTS)에 필요한 기능을 사용합니다. 마이크·카메라·연락처 권한은 사용하지 않습니다.

4. 얼마나 보관하고 어떻게 삭제하나요?
  • 기기 내부 기록: 사용자가 삭제할 때까지 보관되며 ‘나 → 내 정보 · 설정 → 기록 관리 → 전체 지우기’에서 삭제할 수 있습니다.
  • 마음프로 기기 내 대화: ‘새 대화로 비우기’로 삭제할 수 있습니다.
  • 백업 파일: 사용자가 직접 보관·삭제합니다.
  • 앱 의견: 운영 목적 달성 후 삭제하며, 장기 보관이 필요하지 않은 경우 1년 이내 정리합니다.
  • OpenAI API 처리 데이터: OpenAI 정책에 따라 입력·출력이 최대 30일 보관될 수 있습니다.

일반 사용자 계정이 없으므로 별도의 회원탈퇴 절차는 없습니다.

5. 이용하는 외부 서비스
  • GitHub Pages — 웹앱과 개인정보처리방침 제공
  • Google Apps Script / Google Sheets — 자원목록 제공, 의견 접수, 마음프로 API 중계
  • OpenAI API — 마음프로 일반 대화의 AI 답변 생성

Google과 OpenAI는 글로벌 인프라를 사용하므로 관련 데이터가 대한민국 밖에서 처리될 수 있습니다. OpenAI API의 입력·출력은 기본적으로 모델 학습에 사용되지 않으며, 일반 API 정책상 최대 30일 보관될 수 있습니다.

OpenAI API 데이터 처리 안내

6. 이용자의 선택과 문의
  • 위치 권한, 마음프로, 의견 보내기는 사용자가 선택할 수 있습니다.
  • 기기 기록은 언제든 내보내기·불러오기·삭제할 수 있습니다.
  • 앱에서 외부 사이트를 직접 연 이후에는 해당 서비스의 개인정보처리방침이 적용됩니다.
